keep4mac 설치 안내
==================

처음 실행할 때 "확인되지 않은 개발자" 보안 경고가 나타납니다.
아래 방법 중 하나로 간단히 해결하실 수 있습니다.


[ 방법 1 ] 설치 도우미 사용 (가장 쉬움)
-----------------------------------------
1. keep4mac.app을 Applications 폴더로 드래그합니다
2. 이 DMG 창에서 "처음 실행하기.command"를 더블클릭합니다
3. "허용" 또는 "열기" 버튼을 클릭합니다
4. Terminal 창이 열리면서 자동으로 보안 설정 해제 후 앱을 실행합니다


[ 방법 2 ] 우클릭으로 열기
---------------------------
1. Applications 폴더에서 keep4mac 앱을 우클릭(또는 Control+클릭)합니다
2. 메뉴에서 "열기(Open)"를 선택합니다
3. 경고 창에서 "열기" 버튼을 클릭합니다

※ 최초 1회만 이 과정이 필요합니다.
   이후에는 그냥 더블클릭으로 실행됩니다.


[ 방법 3 ] 터미널 명령어
------------------------
터미널 앱을 열고 아래 명령어를 붙여넣기 후 Enter를 누릅니다:

  xattr -cr /Applications/keep4mac.app


설치 순서
---------
1. keep4mac.app을 오른쪽 Applications 폴더로 드래그합니다
2. 위 방법 중 하나로 최초 실행합니다
3. "Google로 로그인" 버튼을 클릭하면 Chromium 브라우저가 열립니다
4. Google 계정으로 로그인하면 자동으로 연결됩니다
