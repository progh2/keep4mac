keep4mac 설치 안내
==================


[ 방법 1 ] PKG 인스톨러 사용 (권장)
--------------------------------------
1. "keep4mac 설치하기.pkg"를 더블클릭합니다
2. "확인할 수 없는 개발자" 경고가 뜨면:
   - 시스템 설정 → 개인 정보 보호 및 보안 → "그래도 열기" 클릭
   - 또는 pkg 파일을 우클릭 → "열기" → "열기" 클릭
3. 설치 마법사를 따라 진행하면 자동으로 설치됩니다
4. 설치 후에는 보안 경고 없이 바로 실행됩니다 ✓


[ 방법 2 ] 직접 드래그 설치
-----------------------------
1. keep4mac.app을 오른쪽 Applications 폴더로 드래그합니다
2. 최초 실행 시 보안 경고가 뜨면:
   - Applications에서 keep4mac 앱을 우클릭 → "열기" 선택
   - 경고 창에서 "열기" 클릭 (최초 1회만 필요)
